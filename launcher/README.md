# 一键启动

双击「启动动效工作台.app」，自动在后台启动服务并在默认浏览器打开正式资产库。已有服务时直接打开，不重复启动。关闭浏览器不会停止服务；重启电脑后再次双击即可。

## 移动位置

启动应用可以放到任意位置。项目文件夹也可以整体移动或改名，保留其中的文件结构即可。

入口依次查找应用所在文件夹、同目录的「动效工作台」、上次记住的项目位置、桌面的「动效工作台」。找不到时会弹出文件夹选择框，选择包含 `prototype` 的项目文件夹即可，以后会记住新位置。取消选择不会修改数据。

应用是启动入口，资产数据仍在项目文件夹内，不能只保留应用并删除项目。若服务仍在运行，移动项目后建议重启电脑再启用，避免旧进程继续使用原路径。

日志：项目 `.runtime/server.log`。手动启动：`/bin/zsh launcher/start-workbench.sh --no-open`。

## 重新构建入口

在项目根目录执行：

```sh
osacompile -o '启动动效工作台.app' launcher/Workbench.applescript
cp launcher/start-workbench.sh '启动动效工作台.app/Contents/Resources/start-workbench.sh'
```

编译后的应用已内置启动脚本，无需修改任何绝对路径。
