# 视频复刻：重复问题与预防规则

记录来源：Finqube、Trading、Discipline 多轮用户反馈。此文件需在每次新复刻前读取；新反馈补充到这里。它规定本工作区工作方法，不声称在别的项目会自动加载。

## 1. 分镜与排版：避免把视频当作 PPT

先建立逐镜时间表，标注唯一主要焦点、可读时段、出入画方式和衔接方向。不要默认加入页眉、页脚、页码、大标题加副标题。不要仅用 Flex/Grid 中心排版轮换信息；允许 CSS，但构图和时序必须来自参考。

主体文字（如 Extreme discipline、价格、任务、Share）和上方旁白小字幕分开处理。用户明确要求去掉小字幕；后续默认不附加小字幕。需要保留的文字应按采样时点校准，避免把所有词统一渐显。记录参考误差范围，不声称未做过的逐帧/音素对齐。

## 2. 三维视差不能用整体缩放代替

拆开背景、主体、前景标注，不把全部内容放进一张 SVG/截图后整体旋转。至少两个不同深度的可见元素，在同一段移动里呈现不同屏幕位移。明确相机位置、目标、空间槽位和前后遮挡。

CSS 实现要检查 preserve-3d；不要在空间父容器加 filter、opacity、overflow 等导致后代压平的属性。必要滤镜放在叶子层。镜头有透视不代表物体已有厚度；纸页、翻转卡片要有正反面和合理旋转轴。

## 3. 回弹、惯性与连续运镜

不要只有渐显和匀速平移。按原片选择快速启动、长减速、错峰进入、过冲与余摆；不是所有元素都强行套弹簧。

跨中间控制点避免速度归零后重启。分轴处理位移、旋转、注视点；连续样条需检查路径及时间参数的连续性。角色/组件的小动作和引导球、光标、连线属于主复刻范围，不得省略。

日历是每张固定内容的纸页绕装订轴转动，不是定时换数字和重置同一张页面角度。抽查至少四个翻页阶段，验证正反面、遮挡、支架位置和整页运动。

## 4. 运动模糊与景深分开

运动模糊：确认最终成片真的经过时间采样或速度模糊管线。记录子样本数、快门时长和输出帧率；不能用全局高斯模糊充当动感。高速段看方向性拖尾，停稳段必须恢复清晰。仅加大采样数不等于加大快门。

景深：每镜明确主焦点及它的范围。主焦点文字和轮廓保持清晰，其他深度层适度虚化。禁止默认在整屏覆盖径向 backdrop blur——移动主体可能被误伤。为焦平面留清晰区间，限制最大模糊，焦点转移不要长时间两端都虚。

## 5. 背景、材质、光效不是装饰补丁

对照亮斑移动路径、速度、面积、明暗切换与镜头的相对位移。不能用几个慢速呼吸的模糊圆概括所有背景。优先保持跨镜时间连续。

玻璃需要透光/反射层次、边缘光和背景关系，不能只降低 opacity。鱼眼需要实际像素畸变，不能用缩放冒充。明确说明近似材质与真实光学的差别。

## 6. 交付前检查（主动完成）

- 看整条分镜覆盖，不能把局部六秒当整条完成。
- 关键运动段按连续帧检查：日历、文字穿梭、相机掠镜、焦点切换；静态联系表只用于构图和缺失检查，不能证明运动丝滑。
- 抽取焦点最清晰时与最快时：可读性、拖尾、遮挡和穿插。
- 核对时长、帧率、音轨、同步滑块、版本切换与下载链接。
- 不把未经观察的视觉效果说成已验证；用户要求跳过检查时遵从并明确哪些未检查。

## 7. 入库必须保存真实实现

按确认版本的冻结快照打包。风格须保存自己的真实配色、材质、背景参数，禁止只改名字复用旧风格。模板保存时序、布局、组件、依赖与效果管线。

配置中的入口/导出符号必须存在；npm run render 必须有效；说明预渲染片段、源码修改方式和未暴露的参数。正式资产必须能预览、复制调用配置、删除。用户授权修订后直接入库时自动完成，不再多问一次。

## 8. 去风格预览（后续复刻默认必做）

先完成复刻版，再沿用同版运动计算生成纯几何版；两版共享时序、变换、深度、焦点和已有曝光管线。去掉可见文案、字体、照片、配色和材质装饰，不用全片灰度滤镜冒充。预渲染嵌套片段也需要中性重渲染。库内同一模板提供两种预览，调用入口明确区分纯动效与原复刻；原版快照和发布包保留。细则见根 AGENTS.md「双版本复刻与动效库」。
