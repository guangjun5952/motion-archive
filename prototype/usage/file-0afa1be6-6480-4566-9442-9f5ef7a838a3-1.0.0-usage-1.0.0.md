# 研宋 · 使用说明

作为目标工程的字体文件加载，使用前检查实际字形覆盖。

资产版本：1.0.0；说明版本：1.0.0

## 适合
- 需要当前字体外观的主体文字或标签

## 不适合
- 未经检查直接认定支持所有中文、英文或字重

## 参数
- **fontFamily** (consumer)：加载后的字体名称。绑定：FontFace + document.fonts.add；目标组件 fontFamily。

## 调用示例（调用计划，不等于已经渲染）
```json
{
  "variant": "file"
}
```

## 入口
- file: /uploads/file-0afa1be6-6480-4566-9442-9f5ef7a838a3.ttf；目标工程加载；未声明运行时参数透传

## 限制
- 字形覆盖和授权范围未自动验证；字体替换后检查换行及排版。

验证级别：file-import。本次元数据补录不等于新的视觉或渲染验收。
