# 深蓝银白柔光 · 使用说明

深蓝底与银白光斑移动。

资产版本：1.0.0；说明版本：1.0.0

## 适合
- 需要现成动态光效或纹理作为画面底层

## 不适合
- 需要修改素材内部光效、物体或文字的独立图层

## 参数
- **fit** (consumer)：填充方式。绑定：目标 Img / OffthreadVideo 的 style.objectFit。cover 可能裁切；contain 保留完整图像但可能留边。
- **muted** (consumer)：背景静音。绑定：目标 OffthreadVideo 的 muted。原文件保留音轨；工作台预览静音，目标工程需显式设置。

## 调用示例（调用计划，不等于已经渲染）
```json
{
  "variant": "file"
}
```

## 入口
- file: /uploads/file-1201091b-9e2e-4451-89a1-cf3e8896c02f.mp4；目标工程加载；未声明运行时参数透传

## 限制
- 白色光斑可能降低浅色文字对比。
- 按原始画幅导入，未生成独立横竖屏构图版本；填充裁切不等于完成适配。
- 保留原文件像素与音轨，媒体内部内容不可分层编辑。

验证级别：file-import-and-sample-review。本次元数据补录不等于新的视觉或渲染验收。
